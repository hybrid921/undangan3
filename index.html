Cara mengganti foto: siapkan gambar JPG, beri nama file persis seperti daftar di atas, lalu letakkan di folder foto. Jika nama file sama, pilih “replace/ganti file” saat mengunggah ke hosting. Untuk mengganti nama pasangan, edit nilai COUPLE_NAMES di file script.js.

Privasi pengeditan: halaman undangan tidak lagi menyediakan tombol unggah atau ubah nama untuk pengunjung. Pada GitHub Pages, hanya pemilik repository dan kolaborator yang diberi izin dapat mengubah file website.
